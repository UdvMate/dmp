# DMProjekt – AI tanulókártya alkalmazás

Ez a projekt egy natív asztali alkalmazás, amely tanulókártyák (flashcardok) kezelésére szolgál. A felhasználók saját kártyaszettjeiket hozhatják létre, rendszerezhetik, és gyakorolhatják a tananyagot.

### Projektfájlok elérési útjai

# 🔧 Szoftver forráskódja
**Elérési út:**  
`/src/`  
A teljes forráskód a `src` mappában található.

# 🖥️ Telepítőkészlet (Windows)
**Elérési út:**  
`/release/DMP_Setup.exe`  
A program telepítéséhez futtassa ezt a fájlt.

# 🗄️ Adatbázis export (dump)
**Elérési út:**  
`/database/dmp_dump.sql`  
Ez a fájl tartalmazza a MySQL adatbázis exportját.

# 📚 Dokumentáció
**Elérési út:**  
`/docs/`
A dokumentáció az alábbi fájlokat tartalmazza:

- `dokumentacio.md` – A szoftver működésének részletes leírása  
- `tesztek.md` – A tesztekhez kapcsolódó kódrészletek és eredmények  
- `adatbazis_diagram.png` – Az adatbázis szerkezetének vizuális ábrája (ER-diagram)
